# LangChain RAG 基础知识 · 学习笔记目录

21 个编号脚本 + 1 个补充脚本，按编号顺序即学习路径。每个脚本是一个独立可运行的知识点练习。

## 一、模型基础（1-4）

| 脚本 | 知识点 |
|---|---|
| `1.langchain调用千问和本地大模型.py` | langchain 接入通义千问 API 与本地大模型（Ollama）两种方式 |
| `2.langchain的流式输出.py` | `.stream()` 逐字输出，打字机效果 |
| `3.langchain调用对话模型.py` | ChatModel 基本调用，System/Human/AI 三种消息角色 |
| `4.langchain调用嵌入模型.py` | Embeddings 模型：文本转向量 |

## 二、提示词工程（5-7）

| 脚本 | 知识点 |
|---|---|
| `5.langchain通用提示词模板.py` | PromptTemplate 变量填充 |
| `6.few_shot_template提示词模板.py` | 少样本示例模板，让模型模仿示例格式输出 |
| `7.ChatPromptTemplate的使用和MassagePlaceholder.py` | 对话模板 + MessagesPlaceholder 插入历史消息 |

## 三、链与输出解析（8-11）

## 学习路径总结

```
模型调用 → 提示词 → 链式编排(LCEL) → 输出解析 → 会话记忆
    → 文档加载 → 切片 → 向量库 → 检索增强(RAG) → 工具调用 → Agent
```

学完这些，就可以看懂根目录的简易 RAG 问答应用（知识点的综合练习）和
`agent项目/` 的医学健康 Agent（进阶实战）了。
